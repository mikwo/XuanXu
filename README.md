# 玄枢 · 四柱排盘

纯静态的八字排盘页：**双击 `index.html` 就能用**，零依赖、零构建、不联网、不上传任何数据。

四柱、大运、流年、十神、神煞、格局、用神全部在本机算出；每一条断语都能点开看它从哪本书、哪一句来。

## 快速开始

```bash
git clone https://github.com/mikwo/XuanXu.git
cd XuanXu/bazi
# 直接双击 index.html；或起一个静态服务器：
python -m http.server 8000   # 然后打开 http://localhost:8000
```

打开后是**空盘**：填入公历生日、出生时刻，选乾造／坤造，点「起盘」。出生地经度可填可不填——不填按东八区 120°E，填了就按真太阳时定时柱。

> 本仓库不含任何真实生辰。测试夹具用 `1990-04-15 09:30 男` 作中性样例。

## 功能

- **命盘**：四柱表（主星／天干／地支／藏干／星运／自坐／空亡／纳音／神煞）、五行消长、三张摘要卡（日主·格局·用神），以及「凭什么这么判」五个折叠：日主强弱、格局怎么定、用神喜忌、神煞与藏干、两法取用（调候 vs 扶抑，附原文）。
- **运势**：十步大运轨道，点任一步看该十年详情与十个流年；流年可再展开。
- **解读**：日主性格、事业、财与守、婚恋、健康、六亲晚运、用神改运，七折全部由盘面数据生成。
- **词解**：十神、十二长生、神煞、五行与象、基础概念、神煞的生成规则、一星三说（羊刃）、调候用神、规则与出处。每张词卡底部一行小字标出处，指不到书的直书「无单条定义」。
- **典籍**：《滴天髓輯要》42 篇、《穷通宝鉴》116 段原文，左目录右正文，可逐篇翻阅。
- **浮窗**：虚线词悬停即看，分「原文 · 推演 · 古断 · 注解」四层，**每层各自标出处**；内容长时可点一下固定、内部滚动、Esc 关闭。

## 技术约定

**刻意不用 ES Module，用经典脚本共享全局作用域。** 理由只有一条：`file://` 下浏览器禁止 `import`，改成 ES Module 就必须起本地服务器，「双击即用」就没了。于是改由**文件名编号**承担加载顺序，三条纪律：

1. **只能向后依赖**：`12-compute.js` 可以调 `11-ganzhi.js`，反过来不行。
2. **编号即契约**：重排、重命名会静默改变行为，改完必须跑 `golden`。
3. **数据文件里不写流程**：`04/05/07/08/09` 只有表与释义；一旦掺进计算，就再也说不清「这条断语从哪来」。

想改成 ES Module 也不难：每个文件加 `export`、`index.html` 换成单个 `<script type="module">`，再起静态服务器。现在的写法不是技术债，是一个明确交换——**用全局作用域换双击可运行**。

## 数据与出处

- **《穷通宝鉴》**：维基文库简体本，解析为 **116 段**，十干十二月 **120 格**逐格标出取文情形——**98 格本篇单论、3 格一篇合论数月、17 格此月未单列而取该季总论、2 格原书确未列（乙十二月、戊十二月，不代拟）**。页面据此标明是单论、合论还是季总论。
- **《滴天髓輯要》**（清·陳之遴素庵輯）：42 篇全取，繁体照录。**注是素庵注，不是任鐵樵注**。另一本《滴天髓闡微》的维基文库本 OCR 讹误太多（「衰右有旺者存」应为「衰中」），已弃用。
- **《三命通会》**：不逐卷转录，只取本页用到的篇（卷二论将星华盖、卷三论天乙／太极／羊刃／劫煞亡神／孤辰寡宿／天罗地网／十恶大败等），以十二卷全本文本与 ctext 清录九卷本互校。
- **「国印贵人」查无此章**：可核的本子里（ctext 清录九卷本、四库本两版十二卷、维基四库本卷十一与十二）逐卷检索均无「國印」二字，而今人辞书多把它归给《三命通会》却不标篇名。故页面里该星只作「传引 · 篇名无考」，断语按名义取象处理，不冒充原文。
- `data/*.json` 是解析中间产物，页面真源仍是 `js/`；改数据请改 `js`。

## 测试

```bash
cd bazi
node tests/run-tests.mjs    # 189 条断言
node tests/golden.mjs       # 121 例金标
node tests/stress.mjs       # 2000 造压力
```

| 测试 | 锁住什么 | 失败通常意味着 |
|---|---|---|
| `run-tests` | 样例盘四柱/十神/星运/神煞、节气与换日边界、真太阳时、神煞查法、引文层完整性、词解与典籍页渲染、起盘栏与空盘状态 | 算法或文案被改坏 |
| `golden` | `compute()` 对 121 组输入的逐字节输出（sha256 前 16 位） | 任何「以为是重构」的行为改动 |
| `stress` | 1900–2100 年、24 时、73–135°E 随机 2000 造的全页渲染与浮窗 | 某类命造会抛错或渲染出 `undefined/NaN` |

金标由 LCG（种子 `19900415`）生成，首例固定为中性样例，可复现。重录金标只有两个正当理由：算法真的变了，或数据源换了——两种情况都要在 `golden.json` 的 `note` 里写明。

## 已知边界（写在明处）

1. 节气用低精度 Meeus 公式，实测与历书差数分钟，最坏约 15 分钟；出生时刻离换节 20 分钟内会**报警**（`#warn`），此时月柱可能差一格。
2. 23:00 固定为子初换日（《三命通会·论时刻》），不设开关——另一派「子正换日」无宋明原文。
3. 神煞只做 24 种；羊刃取法留一个开关（通会「禄前一辰」↔ 子平「惟五阳」），因为两本书都有明文且结论相左。其余异说拿不出原文，一律不摆选项。
4. 强弱、用神分值是**自设扶抑模型，非古法**，页面与词解「规则与出处」都已明说：方向可看，分不可执。
5. 大运流年只按五行喜忌打分，未加刑冲合害的加减。
6. 原文层可核：凡引书名，均可在 `js/22-sources.js` 或 `04/05` 找到对应原文；推演层、权衡层、解读文字是本页推理，浮窗内逐层标出。
